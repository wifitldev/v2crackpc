# v2crackN — ПК-версия v2crackNG

Форк [2dust/v2rayN](https://github.com/2dust/v2rayN) (GUI-клиент для Windows/Linux/macOS) с доработками,
перенесёнными из Android-форка **v2crackNG** (`C:\Users\Naumov\Documents\ng`).

Каталог: `C:\Users\Naumov\Documents\v2crackN`

## 1. Что перенесено из v2crackNG

### 1.1. Брендирование

| Что | Где |
|---|---|
| Имя приложения `v2crackN` (диалоги, User-Agent, автозапуск, папка данных, WebDAV-бэкап) | `v2rayN\ServiceLib\Global.cs` → `AppName` |
| Имя процесса/EXE: `v2crackN.exe` | `v2rayN\v2rayN\v2rayN.csproj`, `v2rayN\v2rayN.Desktop\v2rayN.Desktop.csproj` → `AssemblyName` |
| Заголовок главного окна | `v2rayN\Views\MainWindow.xaml`, `v2rayN.Desktop\Views\MainWindow.axaml` |
| Метаданные сборки (`Product`, `Authors`, `Description`) | `*.csproj`, `v2rayN\Directory.Build.props` |
| Путь `%LocalAppData%` для данных приложения | `ServiceLib\Common\Utils.cs` → `StartupPath()` |
| URI ресурсов Avalonia `avares://v2crackN/Assets/` | `ServiceLib\Global.cs` → `AvaAssets` |

> Иконки (`Resources\v2rayN.ico`, `NotifyIcon1..4.ico`) пока **остались от v2rayN** — это отдельная задача.

### 1.2. Свои обновления

- Репозиторий для самобновления: `Global.AppRepo = "wifitldev/v2crackpc"`.
  Подхватывается через `Global.CoreUrls[ECoreType.v2rayN]` → меню **Help → Check Update**
  (`ServiceLib\ViewModels\CheckUpdateViewModel.cs`, `ServiceLib\Services\UpdateService.cs`).
- Имена ассетов релиза задаются константой `Global.AppReleaseAssetName` (`v2crackN`)
  и подставляются в `ServiceLib\Manager\CoreInfoManager.cs`.
- Страница релизов: `Global.AppReleasePageUrl`.

**Проверка версии на старте — ВЫКЛЮЧЕНА** (собственного эндпоинта нет, он отвечает 404):
- вызов закомментирован в `ServiceLib\ViewModels\MainWindowViewModel.cs` → `Init()`;
- `Global.AppVersionCheckUrl = ""` — запрос не отправляется даже при раскомментировании;
- реализация сохранена: `ServiceLib\Services\BackendVersionCheckService.cs`
  + метод `MainWindowViewModel.CheckBackendVersionAsync()` + обработчики `ShowYesNoInteraction`
  в `v2rayN\Views\MainWindow.xaml.cs` и `v2rayN.Desktop\Views\MainWindow.axaml.cs`.

Чтобы вернуть: раскомментировать вызов в `Init()` и вписать URL в `Global.AppVersionCheckUrl`.

### 1.3. Принудительная (вечная) подписка

Константы в `ServiceLib\Global.cs`:

```csharp
PermanentSubId        = "permanent_v2crackn"
PermanentSubRemarks   = "✨ Community ✨"
PermanentSubUrl       = "<адрес вашей подписки>"
PermanentSubAutoUpdateInterval = 60
```

Логика:

| Место | Что делает |
|---|---|
| `ConfigHandler.EnsurePermanentSubscription()` | создаёт подписку, если её нет, и **каждый раз** на откатывает `Id/Url/Remarks/Enabled` обратно |
| `AppManager.InitApp()` | вызывает `EnsurePermanentSubscription()` при каждом старте |
| `MainWindowViewModel.Init()` | через 3 с после старта обновляет подписку напрямую (без прокси) |
| `ConfigHandler.DeleteSubItem()` | возвращает `-1` для `PermanentSubId` — удалить нельзя |
| `ConfigHandler.AddSubItem()` | игнорирует попытку переименовать/перенаправить подписку |
| `SubSettingViewModel` | кнопки **Delete**/**Edit** отключены для вечной подписки, **Share** работает |

Проверено вживую: ноды импортируются, при смене адреса подписки
существующая БД переписывается автоматически (старый URL заменяется, 0 старых вхождений).

### 1.4. Пресеты маршрутизации RU/IR

**Переносить не пришлось — в v2rayN они уже есть из коробки:**

- `ServiceLib\Enums\EPresetType.cs` → `Default / Russia / Iran`
- `ConfigHandler.ApplyRegionalPreset()` — подменяет источники `geoip/geosite`, `.srs`-правил, шаблонов
  маршрутизации и DNS на `runetfreedom/russia-v2ray-rules-dat` / `Chocolate4U/Iran-v2ray-rules`
- Источники: `Global.GeoFilesSources`, `SingboxRulesetSources`, `RoutingRulesSources`, `DNSTemplateSources`
- Меню: **Settings → Regional Presets → Default / Russia / Iran**
  (`MainWindowViewModel.RegionalPreset*Cmd`)

## 2. Как собрать (Windows)

Требуется **.NET SDK 10** (уже установлен: `C:\Program Files\dotnet`, версия 10.0.401).

```powershell
cd C:\Users\Naumov\Documents\v2crackN
dotnet build v2rayN\v2rayN.sln -c Release
```

Результат:

| Проект | Файл |
|---|---|
| WPF (Windows, основной) | `v2rayN\v2rayN\bin\Release\net10.0-windows10.0.19041.0\v2crackN.exe` |
| Avalonia (кроссплатформа: Win/Linux/macOS) | `v2rayN\v2rayN.Desktop\bin\Release\net10.0\v2crackN.exe` |

Тесты:

```powershell
# global.json лежит в корне репо, поэтому запускать надо оттуда
cd C:\Users\Naumov\Documents\v2crackN
dotnet test v2rayN\v2rayN.sln -c Release --no-build
```

**125/125 тестов проходят.**

Сборка под Linux/macOS:

```powershell
dotnet publish v2rayN\v2rayN.Desktop\v2rayN.Desktop.csproj -c Release -r linux-x64 --self-contained
dotnet publish v2rayN\v2rayN.Desktop\v2rayN.Desktop.csproj -c Release -r osx-arm64 --self-contained
```

(в корне репо также лежат готовые `package-debian.sh`, `package-osx.sh` и т.п. от апстрима —
они ожидают имя `v2rayN`, при необходимости нужно поправить под `v2crackN`).

## 3. Как выпустить релиз (свои обновления)

1. Репозиторий: `wifitldev/v2crackpc` (уже создан).
2. Загрузить в релиз ассеты с именами:
   ```
   v2crackN-windows-64.zip
   v2crackN-windows-arm64.zip
   v2crackN-linux-64.zip
   v2crackN-linux-arm64.zip
   v2crackN-macos-64.zip
   v2crackN-macos-arm64.zip
   ```
   (префикс = `Global.AppReleaseAssetName`)
3. Поставить тег вида `v7.25.4` (версия сверяется с `Utils.GetVersionInfo()`,
   текущая — `7.25.4` из `v2rayN\Directory.Build.props`).
4. Проверка: меню **Help → Check Update**.

## 5. Известные мелочи (всё от апстрима, не чинилось)

- В логе при старте встречается `Failed to find a registration for an Interaction`
  в `ProfilesViewModel.RefreshServersBiz` — гонка ReactiveUI, действие перехвачено и залогировано как DEBUG.
- На самом первом запуске (пустая БД) возможен `Arg_NullReferenceException` в `ConfigHandler.GetDefaultRouting`
  — таблица маршрутизации ещё не инициализирована; `StatusBarViewModel.Init()` инициализирует её сразу после.
- `Format_BadBase64Char` при обновлении подписки — норма: содержимое сначала пробуют декодировать из base64,
  получают ошибку и парсят как обычный текст со ссылками.
- Приложение не находит `bin\xray\xray.exe` — ядро Xray нужно положить вручную
  (или скачать через **Help → Check Update**), как и в обычном v2rayN.
